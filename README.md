# About
A random Terminal-based visualizer that I made out of pure boredom for absolutely no reason.
Inspired by Painters from the AP CSA code.org curriculum.

> [!NOTE]
> You need to be running a terminal that supports ANSI codes for this to work.

# Use
After cloning, do...
1. Run `cd /path/to/git/clone/of/repo/`.
2. Run `mkdir bin`.
3. Run `javac -d bin *.java`.
4. Run `java -cp bin Main`.
